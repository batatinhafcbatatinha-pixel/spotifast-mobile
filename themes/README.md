# Community themes

Themes for Spotifast Mobile made by its users. To use one, open its `.json`
file here, tap **Copy raw file**, then in the app open **⋮ → Theme** and tap
**Paste**. Or download the file and use **Import file**.

| Theme | Light or dark | By |
|---|---|---|
| [Solarized Dark](solarized-dark.json) | Dark | Spotifast Mobile |
| [Tokyo Night](tokyo-night.json) | Dark | Spotifast Mobile |
| [Everforest Light](everforest-light.json) | Light | Spotifast Mobile |

## Add yours

1. Make your theme as described in [THEMES.md](../THEMES.md).
2. Add it here as `your-theme-name.json`, in lowercase with dashes, and add a
   row to the table above.
3. Open a pull request with a screenshot of the theme in the app.

The app checks every file in this folder when it is built, so a theme that
does not read fails the check before it is merged.
